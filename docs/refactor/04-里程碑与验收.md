**P0 期间修掉的真实缺陷（都有回归用例）**

1. GUI 入口 `argc=0` → 无参自启动分支不执行（`WinMain` 修）；
2. `build_id` 为空导致配置自检失败（上游在产物落盘后才分配 ImplantBuild UUID）；
3. 注入 PEM 的换行/转义形态不稳（新增 PEM→DER 兜底 + 诊断信息）；
4. **Sliver CA 的 issuer/subject 是空 DN**，mbedTLS 拒收 → 给 vendor 的 mbedTLS 打补丁（见 `third_party/mbedtls/SLIVER-PATCHES.md`）；
5. 服务端未起 `mtls --lport` 时产物静默退出 → 改为重连循环并落日志。

> 两个踩坑记录（已修）：mbedTLS 的裸 ECP API **不支持 X25519**（Montgomery 曲线），必须走 PSA `psa_raw_key_agreement`；monocypher 的 `crypto_eddsa_*` 是 EdDSA-**BLAKE2b** 变体，与 minisign 不兼容，Ed25519 必须用 SHA-512 实现。

## 每阶段红线（不满足不合并）

1. 金标向量回归失败；
2. 产物非静态（`PT_INTERP` 或 VC 运行时导入）；
3. 体积 > 512 KB 且无 issue 记录原因；
4. `src/rpc|wire|transport` 里出现 `#ifdef _WIN32`；
5. 阻塞读没有 `closed` 唤醒路径（会导致 kill/重连漏线程）。
